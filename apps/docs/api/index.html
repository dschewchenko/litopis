@litopis/dom and @litopis/core

API reference

Public values, options and controller methods for the headless core and imperative DOM binding. Framework adapters expose the same option and value contract.

DateValue

Litopis represents a calendar date without a time or time zone. Months and days are one-based; supported years are 1 through 9999.

ts 
interface DateValue {
  readonly day: number;
  readonly month: number;
  readonly year: number;
}
Form boundary

getValue() returns an ISO YYYY-MM-DD string. Use getDate() when the application should keep a typed value.

createDatePicker

Mounts a date field and calendar into an existing element.

ts 
function createDatePicker(
  root: HTMLElement,
  options?: DatePickerOptions,
): DatePickerController;

DatePickerOptions

Option Type Default Description
calendarMode "inline" | "popover" "inline" Renders the calendar in flow or in the browser top layer.
firstDayOfWeek 0 | 1 | … | 6 Locale-derived Overrides the first weekday; Sunday is 0.
inputFormat DateFieldFormat "yyyy-mm-dd" Visible input mask and parsing format.
label string "Date" Visible label and accessible name.
locale string "en-US" BCP 47 locale for labels, names and week data.
min DateValue — Earliest selectable date.
max DateValue — Latest selectable date.
onValueChange (value) => void — Runs after the selected typed value changes.
selected DateValue | null null Initial selected value.
showOutsideDays boolean true Shows dates that fill the first and last calendar week.
showSeason boolean false Adds the season label below the month caption.
showTodayButton boolean false Adds a footer action that selects today.
targetSize "compact" | "comfortable" "compact" Comfortable controls are at least 44 by 44 CSS pixels.
today DateValue Local current date Overrides today for deterministic UI or testing.
todayLabel string "Today" Visible text for the today action.

DatePickerController

Method Result Description
open() void Opens a popover calendar.
close() void Closes a popover calendar and restores its closed state.
toggle() void Toggles popover visibility.
getDate() DateValue | null Returns the selected typed value.
getValue() string Returns ISO YYYY-MM-DD or an empty string.
setDate(value) void Sets or clears selection and updates the input.
setVisibleMonth(value) void Changes the month currently displayed.
setOptions(options) void Replaces options without remounting; selection is preserved unless supplied.
goToToday() void Focuses and reveals today within configured bounds.
destroy() void Removes listeners, generated DOM and Litopis state attributes.

createDateField

Mounts only the masked text field. It is useful when the application provides its own calendar surface or needs typed date entry without a picker.

ts 
const field = createDateField(root, {
  format: "dd.mm.yyyy",
  label: "Invoice date",
  min: { day: 1, month: 1, year: 2026 },
});

field.getDate();
field.getValue();
field.isValid();
field.setDate({ day: 16, month: 7, year: 2026 });
field.destroy();

Core exports

@litopis/core has no DOM dependency and can be used for custom renderers, server-side validation and deterministic calendar calculations.

Date math

addDays, addMonths, addYears, startOfMonth, endOfMonth, getDaysInMonth

Comparison and validation

compareDates, clampDate, isSameDate, isValidDateValue, isDateDisabled

Formatting

formatDate, toIsoDate, toLocalDate, getToday

Calendar state

createCalendarState, createCalendarGrid, moveFocus, focusDate, selectDate, selectFocusedDate
