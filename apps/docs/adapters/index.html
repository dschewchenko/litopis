Adapters

Framework packages are thin wrappers over the same tested engine. Each mounted component owns one controller instance.

Plain DOM

ts 
import { createDatePicker } from "@litopis/dom";

const picker = createDatePicker(root);
picker.getValue();

Web Component

html 
<script type="module" src="/litopis-elements.js"></script>
<litopis-date-picker
  first-day-of-week="1"
  input-format="dd.mm.yyyy"
  label="Start date"
></litopis-date-picker>

React

tsx 
import { LitopisDatePicker } from "@litopis/react";

<LitopisDatePicker
  firstDayOfWeek={1}
  inputFormat="dd.mm.yyyy"
  value={date}
  onValueChange={setDate}
/>

Vue

vue 
<script setup lang="ts">
import { LitopisDatePicker } from "@litopis/vue";
</script>

<LitopisDatePicker
  :options="{ firstDayOfWeek: 1, inputFormat: 'dd.mm.yyyy' }"
  :value="date"
  @value-change="date = $event"
/>

Solid and Svelte

tsx 
import { LitopisDatePicker } from "@litopis/solid";

<LitopisDatePicker value={date()} onValueChange={setDate} />
svelte 
<script lang="ts">
  import { litopisDatePicker } from "@litopis/svelte";
</script>

<div use:litopisDatePicker={{ firstDayOfWeek: 1 }} />

Static sites

Litopis ships npm modules and browser bundles. Static sites can use Web Components or the DOM binding from a CDN with no build step.
