Accessibility

The accessibility contract is product scope, not a polish task. Every adapter must preserve it.

Contract

  • Roving focus inside the calendar grid.
  • Arrow, Home, End, PageUp and PageDown navigation.
  • Full date labels for screen readers.
  • Live month announcements after navigation.
  • Disabled state for min, max and custom rules.
  • Input and calendar relationship semantics.

Reference lessons

Cally documents tested browser and screen-reader pairs and names known range-announcement issues. Litopis should do the same instead of claiming universal accessibility.

Automation

Use unit tests for calendar math, browser tests for keyboard flows and axe checks for static violations. Manual assistive-technology notes stay in the docs until automation can cover them.
