Basic inline picker

Mount one calendar with an initial value and read a stable ISO form value.

Value: select a date
ts 
import { getToday } from "@litopis/core";
import { createDatePicker } from "@litopis/dom";
import "@litopis/dom/styles/base.css";

const picker = createDatePicker(root, {
  label: "Appointment date",
  selected: getToday(),
});

picker.getValue(); // YYYY-MM-DD

Popover date input

Keep the calendar out of document flow while preserving input typing, focus restoration and arrow-key entry into the grid.

Value: none
ts 
createDatePicker(root, {
  calendarMode: "popover",
  inputFormat: "dd.mm.yyyy",
  label: "Departure date",
  showOutsideDays: false,
  targetSize: "comfortable",
});

Bounded booking window

Dates outside the allowed range are disabled by the shared state layer and exposed consistently to every renderer.

Value: none
ts 
import { addDays, getToday } from "@litopis/core";

const today = getToday();

createDatePicker(root, {
  label: "Booking date",
  min: addDays(today, -15),
  max: addDays(today, 15),
  showOutsideDays: false,
});

Three input formats, one value contract

Visible masks match the application, while every controller still returns YYYY-MM-DD from getValue().

ts 
createDatePicker(isoRoot, { inputFormat: "yyyy-mm-dd" });
createDatePicker(europeanRoot, { inputFormat: "dd.mm.yyyy" });
createDatePicker(usRoot, { inputFormat: "mm/dd/yyyy" });

Locale labels and explicit week starts

Native Intl supplies month, weekday and ARIA labels. Week start can follow locale data or be overridden independently.

US locale, Monday override

createDatePicker(usRoot, {
  firstDayOfWeek: 1,
  inputFormat: "mm/dd/yyyy",
  label: "Event date",
  locale: "en-US",

Programmatic controller

Update value, visible month and options without recreating the DOM tree or losing the current selection.

Value: none
ts 
const picker = createDatePicker(root, { today });

picker.setDate(addDays(today, 9));
picker.setVisibleMonth(startOfMonth(addMonths(today, 6)));
picker.goToToday();
picker.setOptions({ showSeason: true, showOutsideDays: false });
picker.setDate(null);

Headless calendar state

Use the DOM-free package for custom renderers, server validation or tests. This state inspector calls @litopis/core directly and generates no calendar markup.

ts 
import {
  createCalendarState,
  moveFocus,
  selectFocusedDate,
} from "@litopis/core";

let state = createCalendarState({ selected: today, today });

state = moveFocus(state, "next-week");
state = selectFocusedDate(state);

state.focusedDate; // { day, month, year }
state.selected;    // { day, month, year } | null
