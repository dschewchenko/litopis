Getting started

Litopis is a portable calendar engine for date fields, date pickers and calendars across DOM, Web Components and framework adapters.

Why Litopis

  • Headless core. Shared date math, focus and validation.
  • Portable. DOM, Web Components, frameworks and static bundles.
  • Easy to style. Classes, data-* states and CSS variables.
  • A11y standards. Built for WCAG and WAI-ARIA patterns.
  • Input ready. Masks, date formats and configurable week starts.

Live demo

The DOM binding and Web Component package share the same headless calendar state from @litopis/core. This demo uses Monday as the first day of week and a DD.MM.YYYY input mask.

Accessibility status

Foundation exists: keyboard navigation, roving focus, labels, disabled states and live announcements. Final claims need axe, browser and screen-reader verification.

Package shape

The public API is split by responsibility. UI adapters should stay thin and avoid copying calendar behavior.

txt 
@litopis/core       Headless calendar state
@litopis/dom        Imperative DOM binding
@litopis/elements   Web Components
@litopis/react      React component
@litopis/vue        Vue component
@litopis/solid      Solid component
@litopis/svelte     Svelte action

Research baseline

The product baseline combines the best parts of DayPicker, Cally, React Aria and Zag without becoming a full design-system kit.
