Litopis date picker

Litopis is Ukrainian for “chronicle”: date fields and calendars for plain DOM, Web Components, React, Vue, Solid and Svelte.

Getting started Integrations

One keyboard contract

Day, month and year views share focus movement, selection and range behavior.

Native forms first

Use one formatted field or two endpoints without inventing a form abstraction.

Core before UI

Calendar state and date math stay independent of the renderer and styling layer.

Styles stay optional

Start with the base CSS or add a focused adapter for a design system.

Bundle size

Minified and gzip-compressed. JavaScript and CSS are measured separately.

JavaScript

Layer Gzip Purpose
Core 3.9 kB Headless state, date math and keyboard navigation.
DOM renderer +11.2 kB Accessible fields, form values and calendar DOM.
Web Component +2.0 kB Custom-element API over the DOM renderer.
Framework adapter +0.2–1.2 kB React, Vue, Solid or Svelte bindings.

The + rows are incremental: DOM requires Core; components and adapters require Core and DOM. Framework runtimes are not included.

ts

Install and mount

sh 
npm install @litopis/dom
ts 
import { createDatePicker } from "@litopis/dom";
import "@litopis/dom/styles/base.css";

const root = document.querySelector<HTMLElement>("#travel-date");

if (root) {
  createDatePicker(root, {
    mode: "popover",
    format: "dd.mm.yyyy",
    label: "Travel date",
    locale: "uk-UA",
  });
}

Styles are optional. Date input and keyboard support still work.
