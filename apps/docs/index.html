Litopis date picker

Date fields and calendars for plain DOM, Web Components, React, Vue, Solid and Svelte.

Install and mount Examples

Example

Type a date using the DD.MM.YYYY mask or move through the calendar with Arrow keys, Home, End, PageUp and PageDown.

No date selected

Install and mount

sh 
npm install @litopis/dom
ts 
import { createDatePicker } from "@litopis/dom";
import "@litopis/dom/styles/base.css";

const root = document.querySelector<HTMLElement>("#travel-date");

if (root) {
  createDatePicker(root, {
    calendarMode: "popover",
    inputFormat: "dd.mm.yyyy",
    label: "Travel date",
    locale: "uk-UA",
  });
}

CSS is optional. Without it, behavior and accessible semantics still work.

Accessibility status

Automated tests cover keyboard interaction, focus restoration and axe in Chromium, Firefox and WebKit. The manual VoiceOver, NVDA and JAWS matrix is not complete.
