Add it to your app

Use this setup in a JavaScript app with a bundler such as Vite.

sh 
npm install @litopis/dom

Put the container inside your form.

html 
<form>
  <div id="travel-date"></div>
</form>

Add the picker to your JavaScript entry file.

js 
import { createDatePicker } from "@litopis/dom";
import "@litopis/dom/styles/base.css";

const root = document.querySelector("#travel-date");

if (root) {
  createDatePicker(root, {
    mode: "popover",
    format: "dd.mm.yyyy",
    label: "Travel date",
    name: "travelDate",
  });
}

The form submits travelDate as YYYY-MM-DD. Framework components handle mounting and cleanup for you. Choose a framework guide. Read form values in a working example.
