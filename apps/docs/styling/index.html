Styling

Litopis should publish stable anatomy and let consumer CSS do the work.

Anatomy

The default DOM output exposes predictable class names and data attributes. These selectors are the styling contract, not implementation details.

css 
.litopis
.litopis[data-calendar-mode="popover"]
.litopis[data-target-size="comfortable"]
.litopis-input
.litopis-grid
.litopis-day[data-selected]
.litopis-day[data-today]
.litopis-day[data-outside-month]
.litopis-month-button
.litopis-year-button

Popover CSS

The popover variant uses the browser top layer and CSS anchors.

css 
.litopis[data-calendar-mode="popover"] .litopis-calendar {
  position: fixed;
  inset: 12px auto auto 12px;
  max-width: calc(100vw - 24px);
  z-index: var(--litopis-popover-z-index, 2147483647);
}

.litopis-calendar[popover]:not(:popover-open) {
  display: none;
}

@supports (top: anchor(bottom)) {
  .litopis[data-calendar-mode="popover"] .litopis-calendar {
    top: anchor(bottom);
    left: anchor(left);
    position-try-fallbacks: flip-block, flip-inline;
  }
}

Tailwind and daisyUI

Consumer apps can include Litopis package files in their Tailwind source scan and style generated anatomy directly. No Litopis daisyUI package is needed.

css 
@import "tailwindcss";
@plugin "daisyui";
@source "../node_modules/@litopis";

Bootstrap

Bootstrap can style Litopis through stable selectors and ordinary CSS.

css 
.litopis-input {
  border: var(--bs-border-width) solid var(--bs-border-color);
  border-radius: var(--bs-border-radius);
  padding: .375rem .75rem;
}

.litopis-day-button {
  border-radius: var(--bs-border-radius-sm);
}

Decision

Ship stable classes, data states and CSS variables. Do not require first-party theme packages.
